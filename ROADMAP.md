# 🗺️ Roadmap de Desenvolvimento: NEON-PHAGE

Este documento descreve a evolução planejada para o protocolo NEON-PHAGE.

## 🟢 Fase 1: O Protótipo (Versão Atual)
*   **Engine Gráfica:** Renderização Canvas 2D com estética Synthwave/Neon.
*   **Física de Entidades:** Movimento fluido, inércia simulada.
*   **Sistema de Crescimento:** Algoritmo de absorção de massa ($Area = \pi r^2$).
*   **IA Básica (Daemons v1.0):** Comportamento de perseguição e fuga baseado em tamanho relativo.
*   **Ambiente:** Grid infinito (simulado) com limites de memória.

## 🟡 Fase 2: Conectividade (Em Breve)
*   **Netcode:** Implementação de WebSockets (Node.js + Socket.io) para multiplayer real.
*   **Leaderboard Global:** Quem é o maior arquivo do servidor?
*   **Chat de Proximidade:** Comunicação em binário/hex com outros jogadores próximos.

## 🔴 Fase 3: Complexidade (Futuro)
*   **Habilidades Ativas:**
    *   *Eject Mass:* Atirar bits de dados para ganhar velocidade ou alimentar aliados.
    *   *Split:* Dividir-se em dois para atacar presas menores.
*   **Boss Battles:** O "Firewall" — uma linha vermelha varrendo o mapa que obriga todos a se moverem.
*   **Skins de Código:** Personalize sua aparência (Matrix, Glitch, Vaporwave).

## 🟣 Fase 4: A Singularidade
*   Integração com IA Generativa para criar lore dinâmica baseada nas partidas.
*   Port para Mobile.
