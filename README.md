# 🧫 Agar (Neon Phage)

[![Netlify Status](https://api.netlify.com/api/v1/badges/your-id/deploy-status)](https://app.netlify.com/sites/your-site/deploys)
[![Status: Active](https://img.shields.io/badge/Status-Active-brightgreen.svg)]()

> A modern, high-performance web-based survival game inspired by Agar.io, featuring smooth physics and neon aesthetics.

## ✨ Features

- **Neon Phage Engine**: High-frequency rendering and smooth physics calculations.
- **Lore Integration**: Immersive world-building documents (`LORE.md`).
- **PWA Ready**: Installable on mobile and desktop via Netlify.
- **Verification Suite**: Built-in scripts for syntax checking and integrity validation.

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript
- **Deployment**: Netlify
- **Automation**: Python-based verification scripts

## 🚀 Getting Started

```bash
# Verify syntax
node check_syntax.js

# Run verification suite
python verify_weaver.py
```

## 🛡️ Antigravity Protocol

This project follows the **Antigravity** code standards:
- **Modular JS**: Logic split across specialized files in the `js/` directory.
- **150-Line Limit**: Keeping script files lean and focused.
- **Pure Web**: No heavy frameworks; focusing on raw DOM performance.
